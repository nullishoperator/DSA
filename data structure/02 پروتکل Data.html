پروتکل Data


هر کلاسی که اضافه میکنیم باید یه سری قرارداد ها رو رعایت کنه
تا بتونه از تایپ Data باشه . این متد ها رو یا باید خودش داشته باشه ، یا از کلاسی ارث ببره که اونا رو داشته باشه

1 : متد insert :

    virtual Data<T> &insert(int index, T val) = 0;

    virtual Data<T> &insert(Special special, T val) = 0;

    virtual Data<T> &insert(T val) = 0;

2 : متد remove :

    virtual Data<T> &remove(int index) = 0;

    virtual Data<T> &remove(Special special) = 0;

    virtual Data<T> &remove() = 0;

3 : متد get :

    virtual T &get(int index) = 0;

    virtual T &get(int index) const=0;

یکیش باید const باشه ، تا فقط read-only باشه ، یکی ش باید رفرنسی به المنت در ایندکس مشخص استراکچر مون برگردونه

4 : متد pointer :

virtual Data<T> *pointer(int n) = 0;

متد پوینتر ، خیلی ساده ست ، پوینتری باید بسازه که به استراکچر مون اشاره کنه ، این پوینتر رو خروجی بده (به همین سادگی )

⭐به همین سادگی میتونیم یه دیتا استراکچر بسازیم !
فقط باید این چهار تا رو پیاده سازی کنیم

این ها چیزایی بود که باید استراکچر هامون رعایت کنن ، بریم ببینیم خود Data چی داره !
